# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-08-19

### Added

- Created `backup.sh`, a reusable Bash backup utility.
- Added command-line arguments for source and destination paths.
- Added validation for missing arguments and nonexistent source directories.
- Added automatic creation of destination directories.
- Added user confirmation before starting a backup.
- Added backup status reporting using `rsync` exit codes.
- Added file and directory count summary.
- Added completion timestamp.


## [0.1.0] - 2026-07-31

### Added

- Initial project directory structure
- Improved project README
- Linux web server project documentation
- Linux web server command reference
