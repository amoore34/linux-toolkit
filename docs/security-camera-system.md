# Security Camera System

## Overview

This project documents building a Linux-based security camera system using IP cameras and a Raspberry Pi. The goal was to create a reliable, self-hosted surveillance solution for monitoring and recording video.

## Objectives

- Connect multiple IP cameras
- Configure RTSP streams
- Record video to network storage
- Access cameras remotely
- Troubleshoot camera connectivity

## Environment

### Hardware

- Raspberry Pi
- IP cameras
- Network storage

### Operating System

- Debian 12

## Skills Learned

- RTSP

- Storage management

## Topics Covered

- Configuring IP cameras
- RTSP stream configuration
- MotionEye setup and troubleshooting
- Recording video to network storage
- Managing storage locations
- SMB file sharing
- Accessing recordings from macOS
- Accessing recordings from Windows
- Network troubleshooting
- Camera connectivity testing
- Remote administration

## Lessons Learned

This project expanded my understanding of IP networking, Linux administration, and video surveillance. Troubleshooting RTSP streams, storage locations, and camera connectivity reinforced the importance of systematic testing and network diagnostics while building a practical self-hosted security system.
