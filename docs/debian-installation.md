# Debian Installation

## Overview

This project documents the installation and configuration of Debian Linux on a Beelink mini PC. The system became my primary Linux workstation for learning system administration, Bash scripting, networking, Git, and self-hosted services.

## Objectives

- Install Debian Linux
- Configure the operating system
- Learn the Linux command line
- Install development tools
- Build a stable Linux environment for daily use

## Hardware

- Beelink BT3 PRO Mini PC
- Intel processor
- Debian 12

## Operating System

- Debian 12

## Skills Learned

- Debian installation
- Linux file system
- Package management
- Terminal navigation
- SSH
- Git
- Bash
- Service management

## Topics Covered

- Installing Debian 12
- Updating the operating system
- Installing software with APT
- Configuring SSH
- Installing Git
- Setting up Python virtual environments
- Installing Node.js and npm
- Installing yt-dlp and FFmpeg
- Installing Browsh
- Troubleshooting package installations
- Managing Linux services
- Remote administration from macOS

## Lessons Learned

This project became the foundation for every Linux project that followed. It provided hands-on experience with installing, configuring, and maintaining a Linux system while solving real-world problems.
