# Linux Web Server

## Overview

As part of a work assignment, I was provided with a Linux virtual machine and tasked with configuring it as a web server. This project introduced me to Linux system administration, the command line, and web server management.

## Objectives

- Learn basic Linux administration
- Connect to the server using SSH
- Install and configure Apache
- Deploy a simple website
- Manage Linux services
- Understand basic networking concepts

## Skills Learned

- Linux command line
- SSH
- Apache HTTP Server
- Bash commands
- System administration
- Git (later used to document the project)

## Technologies

- Linux
- Apache HTTP Server
- Bash
- SSH
